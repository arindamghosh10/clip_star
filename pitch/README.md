# Pitch kit

| File | What it is |
|---|---|
| `EMAIL.md` | The pitch email: subject lines, the main email, two follow-ups, a short DM version, answers to likely replies, and a checklist before sending |
| `email.html` | HTML version of the main email (host `screens/00-hero.jpg` and fill in the links) |
| `tour.html` | The screen-by-screen tour page to link from the email |
| `DEMO_WALKTHROUGH.md` | A click-by-click route through the demo, for calls or self-serve |
| `screens/` | Screenshots of the demo workspace (desktop at 1440 px, plus a phone) and a hero collage |

To rebuild the demo data behind the screenshots, run `python -m clipstar.demo` (see `docs/OPERATIONS.md`). All posts, stats and comments in the demo come from practice accounts and are simulated.
